How Each Number Is Built

All-play replays every completed week as if each team had faced all eleven others on that week's twelve categories. A category the two sides tie splits half a win, exactly as Yahoo scores it. Over a full season that is a 231-game record, which is enough for who you drew to stop mattering.

Innings minimums. Missing 50 innings in a week forfeits all five pitching categories. Week 1 ran Wednesday to Sunday, all twelve teams finished under 50, and every one of them still won pitching categories — Yahoo waived the minimum for the short week, so it is excluded. Judging a manager for missing a minimum that was never enforced would be the worst mistake on this page.

Source. Yahoo's public fantasy API — per-category winners and innings pitched for every matchup of the season, plus the full transaction log. The reconstructed category records match Yahoo's published standings exactly for all twelve teams, which is the check that says the parsing is right.
